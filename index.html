Git Stash Guide

Apne uncommitted changes ko temporarily save karne ka behtareen tarika!

Git Stash Kya Hai?

Jab aap kisi branch par kaam kar rahe hain aur achanak kisi doosri branch par switch karna pade, bina apna adhura kaam commit kiye, tab git stash ka use hota hai. Yeh aapke changes ko ek temporary stack me save kar deta hai aur workspace ko clean kar deta hai.

Important Git Stash Commands

git stash

Apne current changes ko temporarily save karne ke liye.

git stash list

Saare saved stashes ki list dekhne ke liye.

git stash pop

Latest stash ko wapas laane aur list se hatane (apply) ke liye.

git stash apply

Latest stash ko apply karne ke liye lekin list me safe rakhne ke liye.

git stash drop

Kisi specific stash ko delete karne ke liye.

git stash clear

Saare stashes ko ek saath delete karne ke liye.
